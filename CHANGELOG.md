## [Unreleased]

### Added

- Type-safe distance, pace, and speed models using Kotlin value classes.
- Metric and imperial unit conversions.
- Average pace and speed calculations.
- Estimated finish time calculations with optional additional time for stops and delays.
- Support for Kotlin Duration.
- Input validation for calculation arguments and model values.
- Public API documentation with usage examples.
- Kotlin/JVM library targeting Java 11 bytecode.
